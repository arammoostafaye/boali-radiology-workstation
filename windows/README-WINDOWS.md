# اجرای Boali Radiology Suite روی ویندوز — راهنمای کامل

این راهنما نحوه اجرای کامل نرم‌افزار را روی **ویندوز ۱۰ / ۱۱** توضیح می‌دهد.

> **از v1.2.0 هیچ پیش‌نیازی وجود ندارد.** ران‌تایم Python 3.12 (embedded)، ران‌تایم Node.js 22، همه وزن‌های مدل، تمام wheel های پایتون (شامل torch) و **بیلد آمادهٔ Production وب** (خروجی standalone از `next build`) **همه داخل خود بسته** هستند. نه نصب Python لازم است، نه Node.js، نه `npm install`، نه کامپایل اولیه — سرور وب در ~۲ ثانیه بالا می‌آید و مرورگر فقط بعد از پاسخ‌گویی واقعی سرور باز می‌شود.
>
> فایل‌های بزرگ به‌خاطر سقف ۱۰۰ مگابایتی گیت‌هاب به‌صورت قطعه نگهداری می‌شوند (وزن‌های ۴۱۷ مگابایتی در `weights/chunks/`، wheel تورچ ۱۱۴ مگی در `runtime/wheels/chunks/`) و در اولین اجرا **به‌صورت کاملاً محلی** سرهم می‌شوند.

## پیش‌نیازها

| نرم‌افزار | نسخه | لینک |
|---|---|---|
| — | — | **هیچ چیز نصب نیاز نیست** ✅ |

- بستهٔ **Portable** (Release): همه‌چیز از قبل آماده است — فقط extract و اجرا؛ وب هم با بیلت production (پوشهٔ `webapp/`) اجرا می‌شود و در ~۲ ثانیه بالا می‌آید.
- حالت **clone سورس**: وب در حالت dev اجرا می‌شود و فقط `node_modules` یک بار با اینترنت نصب می‌شود؛ بقیه مراحل آفلاین است.
- اگر ران‌تایم‌های bundled به هر دلیلی حذف شده باشند، لانچر به پایتون سیستم برمی‌گردد (3.12 = آفلاین، نسخه‌های دیگر = آنلاین) — ولی این فقط مسیر نجات اضطراری است.

## اجرا (یک کلیک)

فایل زیر را دوبار کلیک کنید:

```
windows\START-BOALI.bat
```

> اگر SmartScreen پیام داد: **More info → Run anyway** (فایل bat محلی است، امضای دیجیتال ندارد).

اسکریپت به‌ترتیب:
1. **ران‌تایم Python 3.12 bundled را آماده می‌کند** (بار اول: استخراج از `runtime/python-3.12.10-embed-amd64.zip` — چند ثانیه). پایتونِ نصب‌شده روی سیستم **کاملاً بی‌اهمیت** است.
2. وابستگی‌های پایتون را **آفلاین** از wheel های داخل بسته نصب می‌کند (`runtime/wheels/` شامل torch 2.11.0+cpu و همه وابستگی‌ها + `python-multipart`). در بستهٔ Portable این مرحله از قبل انجام شده و رد می‌شود.
3. **وزن‌های بزرگ مدل‌ها را از قطعات داخل بسته سرهم می‌کند** (کاملاً آفلاین، با صحت‌سنجی SHA-256). در بستهٔ Portable از قبل سرهم شده است.
4. **ران‌تایم Node.js 22 bundled را آماده می‌کند** (بار اول: استخراج از `runtime/node-v22.23.5-win-x64.zip`).
5. هر سه سرویس را **کاملاً مخفی و در پس‌زمینه** اجرا می‌کند (در بستهٔ Portable، وب با **سرور production از پیش بیل‌شده** اجرا می‌شود — `webapp\server.js`). **دیگر هیچ پنجرهٔ CMD سیاهی روی دسکتاپ باز نمی‌شود** — خروجی هر سه سرویس به‌جای پنجره، در فایل‌های لاگ ذخیره می‌شود:

| سرویس (پس‌زمینه) | پورت | کار | لاگ |
|---|---|---|---|
| `boali-engine` | 3020 | استنتاج واقعی ۵ موتور هوش مصنوعی (YOLO فرکتچر، Bone Suppression، DenseNet-18 ریه، ResNet-50 ماموگرافی، موتور سه‌بعدی CT) | `logs\engine.log` |
| `boali-pacs` | 3021 | آرشیو PACS امن‌شده (۴ فیکس امنیتی) | `logs\pacs.log` |
| `boali-web` | 3000 | رابط کاربری ورک‌استیشن | `logs\web.log` |

6. **صبر می‌کند تا سرور وب واقعاً پاسخ بدهد** و بعد مرورگر را روی `http://localhost:3000` باز می‌کند. دیگر خبری از باز شدن زودهنگام مرورگر و خطای «This site can't be reached» نیست.

> اگر `START-BOALI.bat` را دوباره اجرا کنید در حالی که سرویس‌ها از قبل روشن‌اند، چیزی خراب نمی‌شود: لانچر تشخیص می‌دهد و فقط مرورگر را دوباره باز می‌کند.

## ⚠️ مسیر نصب را کوتاه نگه دارید

لانچر طول مسیر را چک می‌کند و اگر بیشتر از ۱۰۵ کاراکتر بود هشدار می‌دهد. علت: فایل‌های torch مسیرهای نسبیِ تا ~۱۲۰ کاراکتر دارند و ویندوز سقف ۲۶۰ کاراکتر برای مسیر مطلق دارد.

- ✅ خوب: `C:\Boali`
- ✅ خوب: `D:\Boali-Radiology-Workstation`
- ❌ بد: پوشه‌های تودرتوی عمیق مثل `E:\BoneSuppression-Windows\BoneSuppressionAI V\Boali-...-v1.2.0-Windows-Portable\Boali-...-v1.2.0-Windows-Portable`

> نکته: فایل zip دارای پوشهٔ ریشهٔ کوتاه `Boali` است؛ هنگام «Extract All» ویندوز خودش یک پوشهٔ هم‌نام zip می‌سازد، پس نتیجه یک سطح اضافه دارد — اگر مسیر کلی‌تان طولانی است، محتوا را مستقیم در `C:\Boali` استخراج کنید.

## نحوه کار بدون گیت‌وی (مهم)

در محیط توسعه اصلی، درخواست‌های `/api/...?XTransformPort=3020` توسط گیت‌وی Caddy به پورت 3020 هدایت می‌شوند. روی ویندوز Caddy وجود ندارد؛ به همین دلیل یک **پروکسی داخلی Next.js** در `src/app/api/[...engine]/route.ts` ساخته شده که همان الگوی `XTransformPort` را داخل خود Next.js به `127.0.0.1:3020/3021` فوروارد می‌کند. یعنی:

- **هیچ تغییری در کد فرانت‌اند لازم نیست** — همان کد هم در سندباکس و هم در ویندوز کار می‌کند.
- پروکسی فقط پورت‌های مجاز 3020 و 3021 را قبول می‌کند (لیست سفید امنیتی).

## ساختار ران‌تایم‌ها و فایل‌های مدل (همه داخل همین ریپو)

```
runtime/
├── python-3.12.10-embed-amd64.zip      ← ران‌تایم CPython 3.12 ویندوز (11 MB)
├── python312._pth                        ← پیکربندی مسیرهای ران‌تایم (site-packages)
├── node-v22.23.5-win-x64.zip            ← ران‌تایم Node.js 22 ویندوز (35 MB)
├── python\  node\                        ← استخراج‌شده در اولین اجرا (ایجاد خودکار)
└── wheels/                               ← ران‌تایم آفلاین پایتون (win_amd64, CPython 3.12)
    ├── MANIFEST.txt                      ← اندازه + SHA-256 همه ۳۱ wheel
    ├── fastapi, uvicorn, numpy, scipy, opencv, pydicom, pillow, pip, …
    ├── torchvision-0.26.0+cpu-…whl       ← 4 MB  (کامل)
    └── chunks/
        └── torch-2.11.0+cpu-…whl.00/.01  ← 2 قطعه (۹۵ + ۱۹ مگ)

mini-services/boali-engine/weights/
├── MANIFEST.txt                          ← اندازه + SHA-256 همه وزن‌ها
├── fracture_ortho.onnx                   ← 10 MB  (کامل)
├── cxr_densenet18.ts                     ← 29 MB  (کامل)
├── mammo_resnet50.pt                     ← 94 MB  (کامل)
└── chunks/
    ├── bone_suppression.ts.00 … .04      ← 5 قطعه × ~95 MB
    └── lung_component_suppression.ts.00 … .04
```

برای سرهم‌کردن دستی (در صورت نیاز) در هر سیستم‌عاملی:

```
python tools\assemble_weights.py     ← وزن‌های مدل
python tools\assemble_runtime.py     ← wheel تورچ
```

این اسکریپت قطعات را می‌چسباند و **SHA-256** نتیجه را با `MANIFEST.txt` مطابقت می‌دهد.

## رفع اشکال

| مشکل | راه‌حل |
|---|---|
| هشدار «folder path is N characters deep» | بسته را به مسیر کوتاه‌تری مثل `C:\Boali` منتقل کنید (سقف ۲۶۰ کاراکتری ویندوز) |
| «Bundled Python runtime not found» | بسته ناقص extract شده — zip را دوباره کامل استخراج کنید یا Release zip را دانلود کنید |
| «Bundled runtime wheels are missing or corrupt» | `python tools\assemble_runtime.py` را دستی اجرا کنید و پیام خطا را ببینید |
| SmartScreen اجرا را بلاک کرد | More info → Run anyway |
| نصب آفلاین شکست خورد (حالت clone) | لاگ دیتails را ببینید؛ pip خودش لاگ کامل می‌دهد |
| چیپ موتور «deps missing» | فایل `logs\engine.log` را چک کنید — torch باید در `[RUNTIME] Verifying imports` تیک بخورد |
| چیپ موتور «engine offline» | فایل `logs\engine.log` را ببینید (سرویس‌ها دیگر پنجره ندارند — همه‌چیز در لاگ است) |
| چیپ موتور «weights_missing» | `python tools\assemble_weights.py` را اجرا کنید |
| پورت 3000 اشغال است | برنامه دیگری که پورت 3000 را گرفته را ببندید |
| صفحه سفید / خطای اتصال | صبر کنید تا سرور وب بالا بیاید (فایل `logs\web.log`)، سپس F5 بزنید (اولین کامپایل Next.js در حالت dev ممکن است ~۱ دقیقه طول بکشد) |
| آنتی‌ویروس فایل‌های bat/exe را می‌گیرد | استثنا (exclusion) برای پوشهٔ بسته اضافه کنید — همهٔ فایل‌ها محلی و متن‌بازند |

## توقف

چون سرویس‌ها دیگر پنجره ندارند، برای توقف فایل زیر را دوبار کلیک کنید (کنار `START-BOALI.bat`):

```
windows\STOP-BOALI.bat
```

این اسکریپت فقط پروسه‌هایی که در حال گوش‌دادن به پورت‌های 3000 / 3020 / 3021 هستند را می‌بندد و به هیچ برنامهٔ دیگری روی سیستم دست نمی‌زند. برای اجرای مجدد، دوباره `START-BOALI.bat` را اجرا کنید (هیچ نصب و استخراجی تکرار نمی‌شود).


## نکته امنیتی/حقوقی

- این نرم‌افزار برای **تحقیق و آموزش** است؛ ابزار تشخیص پزشکی بالینی نیست.
- وزن‌های Bone Suppression و Lung Component از مدل عمومی **Qure AI** (`qureaiorg/bone-suppression`) هستند و منطق موتورها عیناً از مخزن `arammoostafaye/boali-radiology-suite` پورت شده‌اند؛ هیچ عدد جعلی تولید نمی‌شود — وضعیت واقعی هر موتور روی چیپ همان کارت نمایش داده می‌شود.
