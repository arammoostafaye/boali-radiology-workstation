# اجرای Boali Radiology Suite روی ویندوز — راهنمای کامل

این راهنما نحوه اجرای کامل نرم‌افزار را روی **ویندوز ۱۰ / ۱۱** توضیح می‌دهد.

> **همه مدل‌های هوش مصنوعی داخل خود همین ریپو هستند** — هیچ فایل مدلی هنگام اجرا از اینترنت دانلود نمی‌شود. دو فایل ۴۱۷ مگابایتی (به‌خاطر سقف ۱۰۰ مگابایت گیت‌هاب) به‌صورت قطعه‌های زیر ۱۰۰ مگ در `weights/chunks/` نگهداری می‌شوند و اسکریپت راه‌انداز آن‌ها را در اولین اجرا به‌صورت محلی سرهم می‌کند (چند ثانیه، روی دیسک).

## پیش‌نیازها (فقط بار اول)

| نرم‌افزار | نسخه | لینک |
|---|---|---|
| Python | 3.10 به بالا | https://www.python.org/downloads/ |
| Node.js | LTS (18+) | https://nodejs.org |

> هنگام نصب Python حتماً گزینه **«Add python.exe to PATH»** را تیک بزنید.
> اگر Bun را نصب دارید، نیازی به Node نیست (هر دو پشتیبانی می‌شوند).
> بار اول فقط **وابستگی‌های نرم‌افزاری** (torch نسخه CPU ویندوزی و ...) نصب می‌شوند — حدود ۲۵۰ مگابایت، یک‌بار برای همیشه.

## اجرا (یک کلیک)

فایل زیر را دوبار کلیک کنید:

```
windows\START-BOALI.bat
```

> اگر SmartScreen پیام داد: **More info → Run anyway** (فایل bat محلی است، امضای دیجیتال ندارد).

اسکریپت به‌ترتیب:
1. پایتون را پیدا می‌کند و محیط مجازی `.venv` می‌سازد (بار اول).
2. وابستگی‌های پایتون را نصب می‌کند — شامل **نسخه CPU ویندوزی torch و torchvision** (حدود ۲۵۰ مگابایت، فقط بار اول).
3. **وزن‌های بزرگ مدل‌ها را از قطعات داخل ریپو سرهم می‌کند** (کاملاً آفلاین، با صحت‌سنجی SHA-256 از طریق `tools/assemble_weights.py`).
4. وابستگی‌های وب (`node_modules`) را نصب می‌کند (فقط بار اول).
5. سه سرویس را در سه پنجره مجزا اجرا می‌کند:

| پنجره | پورت | کار |
|---|---|---|
| `boali-engine :3020` | 3020 | استنتاج واقعی ۵ موتور هوش مصنوعی (YOLO فرکتشر، Bone Suppression، DenseNet-18 ریه، ResNet-50 ماموگرافی، موتور سه‌بعدی CT) |
| `boali-pacs :3021` | 3021 | آرشیو PACS امن‌شده (۴ فیکس امنیتی) |
| `boali-web :3000` | 3000 | رابط کاربری ورک‌استیشن |

6. بعد از ~۲۵ ثانیه مرورگر را روی `http://localhost:3000` باز می‌کند.

## نحوه کار بدون گیت‌وی (مهم)

در محیط توسعه اصلی، درخواست‌های `/api/...?XTransformPort=3020` توسط گیت‌وی Caddy به پورت 3020 هدایت می‌شوند. روی ویندوز Caddy وجود ندارد؛ به همین دلیل یک **پروکسی داخلی Next.js** در `src/app/api/[...engine]/route.ts` ساخته شده که همان الگوی `XTransformPort` را داخل خود Next.js به `127.0.0.1:3020/3021` فوروارد می‌کند. یعنی:

- **هیچ تغییری در کد فرانت‌اند لازم نیست** — همان کد هم در سندباکس و هم در ویندوز کار می‌کند.
- پروکسی فقط پورت‌های مجاز 3020 و 3021 را قبول می‌کند (لیست سفید امنیتی).

## فایل‌های مدل‌ها (همه داخل همین ریپو)

```
mini-services/boali-engine/weights/
├── MANIFEST.txt                        ← اندازه + SHA-256 همه وزن‌ها
├── fracture_ortho.onnx                 ← 10 MB  (کامل)
├── cxr_densenet18.ts                   ← 29 MB  (کامل)
├── mammo_resnet50.pt                   ← 94 MB  (کامل)
└── chunks/
    ├── bone_suppression.ts.00 … .04    ← 5 قطعه × ~95 MB
    └── lung_component_suppression.ts.00 … .04

```

برای سرهم‌کردن دستی (در صورت نیاز) در هر سیستم‌عاملی:

```
python tools\assemble_weights.py
```

این اسکریپت قطعات را می‌چسباند و **SHA-256** نتیجه را با `MANIFEST.txt` مطابقت می‌دهد.

## نمونه‌های آماده تست (داخل ریپو)

```
public/samples/                        ← ماموگرافی ۳ نمونه + CT + MR برای تست مستقیم در UI
mini-services/boali-engine/samples/    ← آرشیو دموی PACS + سری CT قفسه سینه برای موتور سه‌بعدی
```

## رفع اشکال

| مشکل | راه‌حل |
|---|---|
| «Python not found» | پایتون را با گزینه PATH نصب کنید؛ یا در اسکریپت `set PY="C:\Path\To\python.exe"` را دستی تنظیم کنید |
| SmartScreen اجرا را بلاک کرد | More info → Run anyway |
| نصب torch شکست خورد | جداگانه اجرا کنید: `.venv\Scripts\pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu` |
| چیپ موتور «deps missing» | یعنی torch نصب نشده — دستور بالا را اجرا کنید |
| چیپ موتور «engine offline» | پنجره `boali-engine :3020` را باز بگذارید و لاگ آن را ببینید |
| چیپ موتور «weights_missing» | `python tools\assemble_weights.py` را اجرا کنید |
| پورت 3000 اشغال است | برنامه دیگری که پورت 3000 را گرفته را ببندید |
| صفحه سفید / خطای اتصال | صبر کنید تا هر سه پنجره سرویس بالا بیایند، سپس F5 بزنید |

## توقف

سه پنجره سرویس را ببندید. برای اجرای مجدد، دوباره `START-BOALI.bat` را اجرا کنید (نصب‌ها و سرهم‌کردن وزن‌ها تکرار نمی‌شوند).

## نکته امنیتی/حقوقی

- این نرم‌افزار برای **تحقیق و آموزش** است؛ ابزار تشخیص پزشکی بالینی نیست.
- وزن‌های Bone Suppression و Lung Component از مدل عمومی **Qure AI** (`qureaiorg/bone-suppression`) هستند و منطق موتورها عیناً از مخزن `arammoostafaye/boali-radiology-suite` پورت شده‌اند؛ هیچ عدد جعلی تولید نمی‌شود — وضعیت واقعی هر موتور روی چیپ همان کارت نمایش داده می‌شود.
